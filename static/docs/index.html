Find nearby stations

Find stations near a specific geographic coordinate. Returns stations within the maximum distance, sorted by proximity.

Authorizations:
ApiKeyHeaderApiKeyBearer
query Parameters
pretty
boolean

Pretty print response

lat
required
number <float>
Example: lat=40.7589

Latitude coordinate

long
required
number <float>
Example: long=-73.9851

Longitude coordinate

count
integer >= 1
Default: 10
Example: count=5

Maximum number of stations to return

maxdistance
number <float> >= 0
Default: 1
Example: maxdistance=1

Maximum distance in miles

Responses

https://api.whentrain.nyc/stations/nearby

Realtime

Get real-time departure times for a station

Get real-time departure information for trains at a specific station. Station ID can include a direction suffix (N for northbound, S for southbound). If no direction is specified, returns departures for both directions.

Authorizations:
ApiKeyHeaderApiKeyBearer
path Parameters
station_id
required
string
Examples:
  • F24N - Station with north direction
  • F24 - Station without direction (returns both N and S)

Station GTFS Stop ID with optional direction suffix (N/S)

query Parameters
pretty
boolean

Pretty print response

Responses

https://api.whentrain.nyc/departures/{station_id}
